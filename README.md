# Skills

Coleção versionada de skills pessoais para o Codex. Cada skill ocupa uma
pasta própria e mantém suas instruções, referências e ferramentas juntas.

## Skills

- `orquestracao-manual` — coordenação de agentes por ponte humana e arquivos
  compartilhados.
- `ler-sessoes` — resumo em texto puro das sessões locais de agentes, para outro
  agente acompanhar o que foi feito.
